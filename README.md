# guia-hospitalar

Exemplo de guia: https://consultorio.live/artigos/o-padrao-tiss-e-o-preenchimento-da-guia-sp-sadt/

Video sobre angular: https://www.youtube.com/watch?v=VumdXFJ4n7o&t=3850s

Doc do angular: https://angular.dev/tools/cli

### Instalar dependencias

```bash
npm install
```

### Inicar o servidor

```bash
ng serve
```

Link: `http://localhost:4200/`
